第 03 章 程序怎样运行

源码是静态文件，进程是操作系统正在执行的程序实例。机器人系统同时运行 Gazebo、传感器适配、定位、Nav2、任务执行器、工具服务器和 GUI。理解进程、环境和退出，是避免“窗口关了但机器人仍运行”的基础。

从文件到进程

运行 python3 script.py 时，操作系统启动 Python 解释器，解释器读脚本并执行。运行 C++ 程序前需要编译与链接：编译把源码转成目标代码，链接把目标代码和库组成可执行程序。共享库通常在启动或运行时加载，因此“编译成功”和“运行能找到库”是两个检查。

每个进程有 PID、父进程、当前目录、环境变量、文件描述符和退出状态。同一脚本可以启动两次，形成不同 PID；一个 ROS 进程也可能承载多个节点。节点名不能替代进程身份。

source 与新 shell

source env.sh 在当前 Bash 中执行环境脚本。里面的 export 会影响之后启动的子进程。bash env.sh 在新的 Bash 进程中执行，它退出后通常不会把变量修改带回父 shell。因此打开新终端后需要重新加载环境。

cd /home/ceihao/robot_project
source optimization_v2/env.sh
printf '%s\n' "$ROS_DISTRO" "$ROS_DOMAIN_ID"
command -v ros2

这是当前机器的环境检查，预期 ROS 发行版为 Jazzy、在线域为项目配置的 119。实际脚本还加载工作区 overlay、库路径和相关限制。不能把旧虚拟机 overlay 与现在的环境任意叠加，否则同名包可能来自不同构建目录。

PATH 控制 shell 查找可执行程序；PYTHONPATH 影响 Python 模块搜索；动态库路径影响链接库查找。它们用途不同，不能通过把所有目录都塞进 PATH 解决所有 ImportError。

为什么使用 subprocess 的参数列表

Python subprocess.Popen 启动子进程后立即返回句柄，subprocess.run 通常等待完成后返回结果。参数用列表传递，例如 ['python3', 'worker.py', '--out', output]，各项边界明确，不需要再经过 shell 分词。

如果设置 shell=True，字符串中的重定向、变量和命令替换可能被 shell 执行。项目路径或参数来自外部输入时，随意拼接字符串还会带来错误执行风险。教材示例均优先使用列表。

实际运行器指定 cwd、env、日志文件和 start_new_session=True。env 是继承环境的副本加上本任务变量；cwd 是该子进程的工作目录；日志文件承接输出；独立会话便于运行器只收尾自己启动的进程。

三种时间不要混用

墙钟时间描述现实持续多久；单调时间 time.monotonic() 适合计算进程超时，因为它不受普通系统时间校准影响；仿真时间来自 /clock，可以变慢、暂停甚至重置。日志的北京时间或 UTC 是事件标签，不能与仿真时间直接相减。

若仿真完成 100 秒，用了现实 250 秒，平均 RTF=100/250=0.4。任务的预算可能还有 200 仿真秒，运行器却已经接近现实超时，两个约束都要检查。Gazebo 暂停时 /clock 不再前进，但进程墙钟看门狗仍可能触发。

退出码和信号

0 常用于成功，非零由程序定义。项目阶段检查的 2 表示未满足通过条件；它可能是 PARTIAL，而不是 Python 语法错误。Unix 信号是另一条控制通道：Ctrl+C 通常向前台进程组发送 SIGINT。程序可以接住信号，设置停止标志，再在 finally 中取消动作、关闭工具、确认停车、释放资源。

SIGTERM 常用于请求终止，SIGKILL 则无法被程序捕获，不会执行正常清理。因此不能把“杀掉进程”当成“工具已经物理停止”。运行器需要先尝试合作退出，超时才升级处理，并把强制退出单独记账。

ps -eo pid,ppid,stat,etime,args

这条命令查看进程。pid 是进程号，ppid 是父进程号，stat 是状态，etime 是已经运行的时间，args 是启动参数。它是观察命令，不会停止任何进程。不要复制一个历史 PID 执行 kill；PID 可以被系统重新分配。

日志为何要分开保存

任务事件回答“发生了什么”，标准错误回答“程序为什么失败”，运行器结果回答“各进程怎样退出”。三者不能互相替代。一个任务可能已保存完整反馈，却在 Gazebo 清理时出现 −11；也可能所有进程正常退出，但任务因预算不足保存 PARTIAL。

JSONL 每行是一条事件，便于流式追加；完整 JSON 适合快照。项目常先写临时文件再 replace，使读者看到旧完整文件或新完整文件，减少读到半截 JSON 的机会。原子替换不自动等于断电后已落盘，持久化强度还取决于同步和文件系统。

完整教学脚本 · 本章完整输出

代码只使用 Python 标准库；合成输入与历史记录在输出 kind 中区分。公共 ROOT、read、wrap、connected 等辅助函数在完整脚本中定义。

def lab03():
    """A child receives a copy of its parent's exported environment."""
    env = os.environ.copy(); env['ROBOT_LESSON'] = 'parent'
    code = "import os; print(os.environ['ROBOT_LESSON']); os.environ['ROBOT_LESSON']='child'"
    run = subprocess.run([sys.executable, '-c', code], env=env,
                         capture_output=True, text=True, timeout=5)
    assert run.returncode == 0 and env['ROBOT_LESSON'] == 'parent'
    return dict(child_stdout=run.stdout.strip(), parent_copy=env['ROBOT_LESSON'],
                exit_code=run.returncode, shell_interpolation=False)

常见故障与答案

新终端找不到 ros2：检查有没有 source，以及 command -v ros2 指向哪里。Python 模块不存在：检查执行的是系统解释器还是 scene 虚拟环境。程序结束但端口占用：确认服务 PID、归属和退出记录，不要系统范围 killall python3。

问：为什么 exec 常放在启动脚本末尾？答：它用目标程序替换当前 shell 进程，减少额外父层，但它不自动管理目标程序后续创建的所有子进程。

问：Ctrl+C 后多久可以关终端？答：以运行器收尾日志、最终结果、车体及工具停止确认作为依据；不要仅凭命令行重新出现推断所有物理状态。
