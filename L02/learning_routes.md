# 三十章学习路线与练习方法

每章采用“具体问题、原理、固定生产代码、离线练习、真实操作边界、故障与自测”的顺序。你不需要第一次就理解所有 C++ 模板和矩阵；先能说明输入输出，再追踪条件与异常分支，最后修改教学例子的一个参数验证理解。

## Windows 阅读路线

下载整个仓库并解压，从根目录 index.html 进入 L02。先读 01–07 章建立终端、语言、ROS、坐标与架构基础，再完整读 08 章，把一个真实三点点喷案例串起来。之后按 09–25 章理解各模块，最后读 26–30 章准备 Linux 操作和研究。

如果尚未安装 Python，先查看每章附带的实际输出，理解代码后再运行。安装了 Python 3 后，在仓库根目录 PowerShell 执行 `py -3 examples\l02\labs.py 12` 可单独学习滤波。三十个练习不启动机器人、不读取系统密码、不连接网络。

## Linux 当前机复现路线

先完成 02、03、05、06、26 章，能够区分两个仓库、解释 source、识别时间与坐标。然后按 27 章先检查 R09，再开只读 GUI，最后一次启动一个短任务。第一次建议三点点喷，因为 08 章提供最完整的历史事件对照。

每次实验记录命令、会话、版本、范围和结果。不要为赶进度同时开启点喷、巡检和割草；会话锁、计算资源和实时传感器都有所有权约束。完整 A1/B1 留在短例与环境确认之后，原 PARTIAL 结果不能被忽略。

## 三次阅读同一段代码

第一次只读函数名、参数、返回值，写一行它解决的问题。第二次沿正常分支追踪一组具体输入，核对输出和单位。第三次选择一个异常输入，说明在哪里拒绝、是否留下日志、是否影响动作所有权。

Python 重点看字典字段、回调、Future、subprocess、文件写入和异常；C++ 重点看类型、引用、资源生命周期、校验、上游库调用和返回状态。生成组件还要读派生器，避免原始文件与当前运行版本混淆。

## 每章学习记录

写下：我原来怎么理解；本章改变了什么；一个公式的变量和单位；一个真实函数的调用者与输出；练习的实际结果；一个常见失败；一个尚未理解的问题。不要只复制源码作为笔记。

推荐在独立笔记目录保存记录，不修改 baseline 快照。若想改变实验输入，可复制教学函数到自己的文件，明确标记新数值，不把输出混入固定验证文件。

## 阶段检查

读完 01–08，能够口头追踪一个服务点从命令到有效反馈。读完 09–17，能够说明一次观测为什么可信或被拒绝。读完 18–25，能够区分规划、控制、决策、动作和账本。读完 26–30，能够独立操作一个有界短例并提交有证据的失败分析。

教材不以背诵全部参数为目标。判断自己是否学会的标准，是能预测一个输入变化会影响哪一层，并用输出验证这个预测。
