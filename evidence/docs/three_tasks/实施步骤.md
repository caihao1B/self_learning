# 三任务改造：R01–R12

保留 S01–S18 原有标准与记录，新的三任务逐步改造使用 R 编号。每步结束均交付真实结果、手工命令、技术与核心代码说明，并明确是否能进入下一步。拆分后的任务共享原地图与感知定位基础，逐个运行，不同时启动三辆车。

|步骤|执行范围|直观检查结果|
|---|---|---|
|R01|独立配置、版本、结果与启动退出|三个独立运行目录；三任务准入后可停车关闭；原验收不变|
|R02|三种车辆尺寸与运动学契约|尺寸图、碰撞轮廓、轴距/轮距/转向限位、理论与实际转弯圆对照|
|R03|独立任务工作量与场景入口|原地图上三个任务的起终点、区域、路径和预计时间图|
|R04|轻量车辆动力学与速度|加减速、制动距离、转弯/倒车实测轨迹；以约束验证速度|
|R05|共用传感器与 RTAB 定位配置|各车传感器覆盖、定位误差和重定位实测，真值不参与在线决策|
|R06|共用可解释 BT 与运动监督|正常、等待、重规划、上报人工的状态及原因可查看|
|R07|点喷专用任务|到点停车→抽象工作动作→反馈账本→下一点，支持残余重试|
|R08|巡迹专用任务|跟踪连接路，停止、绕行与前方同向目标保持距离的独立案例|
|R09|割草专用任务|符合真实底盘转弯约束的条带/地头路径，关闭工具的转场与覆盖账本|
|R10|三任务分别验收|正常和受阻案例，各自给出完成量、残余、风险和人工处理原因|
|R11|模型外观与贴图|不改物理参数的视觉资产与性能对照；修改碰撞或相机视野需复验|
|R12|录制与交付|三个独立真实录像及精简版、启动说明、已验证范围和未完成项|

R02 下一步提示词：

> 执行 R02——三种车辆尺寸与运动学契约。基于 R01 独立任务配置，核实点喷 Husky A200 尺寸参考、巡迹 Jackal 尺寸参考和项目已有 Dino 模型的真实几何与转向方式；先实现简化碰撞体和运动学约束，不急于贴图。不得把视觉模型名称等同于已验证硬件。给出车宽、轴距、轮距、离地间隙、最大转向角、最小转弯半径与工作幅宽的依据及轨迹实测，检查是否适配原道路和条带地头。保留原地图、正式任务、历史验收；新增版本与手工命令、技术原理和 C++/Python 核心代码说明，完成后判断是否可以进入 R03，不自动执行下一步。
