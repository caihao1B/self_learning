## 手工查验

1. Windows 从 GitHub 下载完整 ZIP，全部解压并双击 index.html。断开网络后打开第 14 章并搜索 `GNSS NIS`，确认可以看到结果。
2. 打开源码工作台，筛选 `precision_progress`，跳到第 9 行，搜索 `return` 并点击下一处。
3. 在第 14 章标记读完并写一条笔记。到“我的学习记录”导出 JSON，在另一个浏览器/系统导入并核对。
4. 打开图解和 GUI 截图，确认历史标签；在状态页确认 R10–R12 仍为 PARTIAL。
5. 在线地址使用同一 ChatGPT 账号登录后完成相同操作。在线与离线笔记各自保存，使用导出/导入迁移。
