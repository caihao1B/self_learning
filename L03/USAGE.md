# 学习站使用说明

本站将 L02 三十章教材组织成同一套在线与离线界面。机器人源码基线固定为 `9aff8337b7794f704c5556a973a5220e73f17808`；学习进度只表示你读到哪里，不改变任何机器人验收。

## Windows 直接开始

1. 在线访问发布地址；Sites 默认只允许所有者访问，需要使用创建站点的同一 ChatGPT 账号登录。GitHub 教材仓库与离线阅读不依赖此登录。
2. 离线时，在 self_learning 仓库点击 Code → Download ZIP。使用 Windows 的“全部解压缩”，保留整个目录结构，不在压缩文件预览里直接打开网页。
3. 在解压目录中双击 `index.html`，用 Edge 或 Chrome 打开。无需 Python、Node.js、ROS、npm 或本地服务器。目录名称可以有中文和空格。
4. 正文、跨章搜索、源码阅读、内置图解与历史截图都来自本地文件；只有 GitHub 原文件与外部官方文档需要联网。
5. 如果浏览器或组织策略禁止本地脚本，打开 `L02/index.html` 使用静态阅读版。安装软件或修改策略不是阅读教材的必需条件。

## 搜索与定位

点击顶栏搜索，或按 Ctrl+K（macOS 可用 Command+K）。输入中文概念、英文函数或停止码，例如“精停”“NIS”“WAIT_DEADLINE”。多个以空格分隔的词要求在同一结果中同时出现。搜索按章节/源码/资料分组过滤；结果会定位到具体小节或源码首次命中行。

搜索是本地文字检索，不会调用模型，也不会将关键词发送到服务器。没有结果时缩短词语，或尝试教材中的英文名称。短词可能产生较多代码命中，可选择“仅章节”。

## 读章节与源码

三十章目录保留 L01 的八个学习分部。章节右侧或顶部有小节导航；阅读工具支持调整字号、打印当前章、标记读完。代码框可以复制、折叠与切换换行。复制得到文本，不会自动执行任何 Linux 命令。

“源码工作台”显示固定版本文件、语言、行号、SHA-256、关联章节与函数入口。可输入行号跳转、在文件内查词并切换命中。长行默认横向滚动，切换换行后不会改变真实行号。高亮仅辅助阅读，不代表代码已运行或通过完整分析。

源码与章节都可通过地址栏的 `#` 链接返回同一位置。离线文件地址包含你的本地目录；分享给他人时应分享站点 URL 或 GitHub 路径，而非自己的 C 盘路径。

## 图解、截图与证据

“图解与证据”可以按架构图、GUI 历史截图、文档证据、离线练习输出和使用指南筛选。图片可以放大；证据保留原来源路径与历史语境。

GUI 图片是历史截图。学习站不连接机器人，不显示新的传感器实时数据，不发送速度或工具命令。需要实时观察时，回到第 27、28 章，在 Linux 机器人项目中启动原监视 GUI。

## 学习记录如何保存和迁移

每章可标记完成并填写笔记，内容保存在当前浏览器的本地存储中。正常情况下重新打开同一路径会保留；浏览器隐私模式、清理数据、更换浏览器或移动离线文件可能造成记录不可用。

在线与离线属于不同来源，记录不会自动互通。切换系统前到“我的学习记录”点击“导出学习记录”，保存 JSON 文件；另一台机器用“导入记录”恢复。导入只接受本站 schema、相同机器人基线、1–30 章的有效数据，合并完成标记与非空笔记，不修改教材内容。损坏或版本不匹配的文件会给出错误。

本地存储不可用时，页面会明确提示；当前会话仍可学习，关闭前务必导出。清除学习记录需要确认，只清除本站保存的数据。学习笔记不上传 GitHub 或站点服务器。
